# Flappy Bird

A polished pixel-art arcade game built with Phaser 3.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:8080`.

## Controls

- Click, tap, Space, or Up Arrow to flap
- Escape or the pause button to pause
- Up/Down Arrows and Enter to navigate menus

Sound preferences and the best score are saved locally. The production build also supports offline play after its first successful load.

## Production build

```bash
npm run build
```
